# Handbook Feedback

这里沉淀我在学习 Handbook 过程中发现的问题，让它们可以回流到 Handbook 共建。要求：repo 公开可访问、内容可索引、每条 feedback 尽量包含页面链接、问题描述、建议改法和来源。

## 流程

1. 学习中遇到卡点 / 错别字 / 概念不清 / 资料过期 / 结构建议 → 按 `_template.md` 新建一条 feedback
2. 命名：`YYYY-MM-DD-简短标题.md`
3. 积累到一定数量后，通过 Handbook 的 [参与共建](https://aiweb3.school/zh/handbook/) 入口（GitHub / Telegram）提交回流

## 入口

- Handbook 参与共建：<https://aiweb3.school/zh/handbook/>
- GitHub 仓库：<https://github.com/lxdao-official/aiweb3school>
