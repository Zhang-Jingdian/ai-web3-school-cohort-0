# AI × Web3 School — 个人学习仓库

我的 AI × Web3 School 学习日志与 proof-of-work 工作区。目标不是「把课程读完」，而是理解 AI 与 Web3 真正交叉时的问题，并把学习过程沉淀成可开源、可索引、可复盘的记录。

## 入口链接

- Handbook：<https://aiweb3.school/zh/handbook/>
- WCB 课程页面：<https://web3career.build/zh/programs/AI-Web3-School>
- WCB Learning 页面：<https://web3career.build/zh/programs/AI-Web3-School#tab=learning>

## 隐私提醒

本仓库默认 public，**不要**提交任何隐私信息、API key、助记词、私钥、未公开联系方式、内部会议链接或他人个人数据。

## 目录说明

- `profile.md` — 学员画像
- `learning-plan.md` — 个人学习计划（四阶段纵深路线）
- `daily/` — 每日学习笔记与打卡记录（`YYYY-MM-DD.md`）
- `tasks/` — 任务笔记
- `experiments/` — 实验与最小实践
- `handbook-feedback/` — Handbook 反馈（问题、卡点、纠错、结构建议）
- `hackathon/` — Hackathon 项目材料
- `submissions/` — WCB 提交记录
- `templates/` — 每日笔记与任务笔记模板
